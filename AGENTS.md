- Una tecnología entra solo si resuelve un problema concreto, se entiende su costo y se puede validar con una prueba o escenario.
- Al implementar o estudiar hitos y al practicar entrevistas del proyecto, leer y aplicar [.codex/skills/ai-incident-coach/SKILL.md](.codex/skills/ai-incident-coach/SKILL.md) aunque el usuario no lo mencione. Usar apoyo gradual: ejemplo explicado para conceptos nuevos, modificación pequeña para conceptos vistos e intento independiente cuando ya los haya practicado con comprensión. Seguir una solicitud explícita de implementación directa si la hace.
- No marcar hitos solo por encontrar archivos. Registrar evidencia verificable y capacidad de explicar las decisiones.
- El código está actualmente en `backend/`; `src/` figura en la jerarquía objetivo. No asumir que ya fue migrado.
- Mantener `docs/progress.md` y los documentos de decisión al cambiar alcance o estado. El código actual tiene prioridad sobre las observaciones históricas de progreso.
